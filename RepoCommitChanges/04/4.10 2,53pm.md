Why you might still see “unstyled” page in the browser

Wrong server URL / wrong port: Vite will try 3000 and may fall back to 3001. Use the exact Local URL printed when you run npm run dev. If you open the wrong localhost port, the page will look unstyled.
Browser cache: if an older HTML/CSS is cached, the new styles might not be loaded. Hard-refresh (Ctrl+F5) clears it.
Viewing file:// index.html rather than the dev server or built server — file:// won’t have Vite dev injection or correct asset paths.
Duplicate headers: before I removed the duplicate header in the guidelines page you could see two navs; that’s fixed (NavBar is now shared).
